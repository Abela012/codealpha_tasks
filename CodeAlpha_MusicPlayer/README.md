# CodeAlpha Task 4 — Music Player

Features:
- Play/pause
- Previous/next
- Playlist
- Song title and artist
- Progress bar
- Duration display
- Volume control
- Automatic next-song playback
- Responsive interface

IMPORTANT:
1. Put your own MP3 files inside the `music` folder.
2. Name them `song1.mp3`, `song2.mp3`, and `song3.mp3`, or change the file names in `script.js`.
3. Open `index.html` in a browser.
